<TopicSection id="input-number" title="6. inputNumber">

<KeyIdea>
inputNumber appends a digit to the text box by string concatenation.
</KeyIdea>

- Events must be attached to the number buttons so pressing a number adds it to the box.
- `inputNumber(v)` takes a number v: it reads the current expression, sets it to the expression plus v (plus means concatenation here), and writes it back.
- Eval and math.js both need the whole expression as a string, so the numbers are sent as strings.
- After a refresh (the first test failed because the page was not refreshed), clicking 7, 8, 9 gives 789, and clicking multiple times keeps adding digits.
- The handler is attached to only some buttons here: `onclick` on 7, 8 and 9. The semicolon is optional but the presenter sometimes adds it.

**File:** `calculator/index.html` (fragment)

```javascript
function inputNumber(v) {
  let expression = document.getElementById("expression").value;
  expression = expression + v;
  document.getElementById("expression").value = expression;
}
```

**What each part does:** line 2 reads the box, line 3 appends v, and line 4 writes it back.

> **Added by tutor:** the value of a text box is already a string, so the plus joins text even if a number were passed. In my tested file, buttons with no handler (such as 4) do nothing, because the lecture wires only some buttons.

</TopicSection>

<TopicSection id="input-operator" title="7. inputOperator">

<KeyIdea>
inputOperator works like inputNumber but appends an operator.
</KeyIdea>

- A similar function takes the operator as o and appends it to the expression.
- It is attached as `onclick` on the division button, and similarly on multiplication.
- Test: 7, divide, 8, equals gives 0.875.
- This is a next-level calculator; there are ways to optimise it.

**File:** `calculator/index.html` (fragment)

```javascript
function inputOperator(o) {
  let expression = document.getElementById("expression").value;
  expression = expression + o;
  document.getElementById("expression").value = expression;
}
```

**What each part does:** it has the same three steps as `inputNumber`, with o in place of v.

**Expected output:** clicking 7, /, 8 then = shows 0.875 (tested in jsdom with math.js).
